# تمرين الديربي

صفحة لتنظيم تمرين الكورة: التسجيل لكل تمرين (13 لاعب وخانتين للحراس وقائمة انتظار)، التشكيلة المتوازنة، تسجيل النتائج، الإحصائيات المتراكمة، الألقاب، رجل المباراة، رسوم الملعب، والأرشيف.

الصفحة تشتغل على GitHub Pages، والبيانات تنحفظ في Firebase عشان الكل يشوفها من جواله.

## التجهيز (مرة وحدة)

### 1. مشروع Firebase
1. ادخل [console.firebase.google.com](https://console.firebase.google.com) بحساب Google واضغط **Create a project** (Google Analytics مو لازم).
2. من القائمة: **Build > Authentication > Get started**، ثم من **Sign-in method** فعّل **Anonymous**.
3. من القائمة: **Build > Firestore Database > Create database**، اختر أقرب موقع (مثلاً `europe-west` أو `me-central`) وابدأ بـ **production mode**.
4. في Firestore افتح تبويب **Rules**، الصق محتوى ملف `firestore.rules` واضغط **Publish**.
5. من **Project settings** (أيقونة الترس) > **Your apps** اضغط أيقونة الويب `</>`، سمّه أي اسم، وانسخ القيم `apiKey` و `authDomain` و `projectId` و `appId` إلى ملف `firebase-config.js`.
6. من **Authentication > Settings > Authorized domains** أضف `اسمك.github.io`.

> مفتاح `apiKey` في Firebase مو سري، عادي يكون في الصفحة. الحماية تكون من قواعد Firestore.

### 2. GitHub Pages
من إعدادات المستودع: **Settings > Pages**، اختر **Deploy from a branch**، الفرع `main` والمجلد `/ (root)`. بعد دقيقة يصير الرابط `https://اسمك.github.io/اسم-المستودع/`.

### 3. أول دخول
أول واحد يفتح الرابط يحط **رمز القروب** (يرسله للشباب) و**رمز المشرف** (يحتفظ فيه). لذلك افتحه أنت أول قبل ما ترسله.

## مين يسوي إيش
- **الكل (برمز القروب):** يسجل اسمه لاعب أو حارس، ينسحب، يشوف التشكيلة والإحصائيات والألقاب، يصوّت لرجل المباراة إذا لعب، ينسخ الآيبان أو رقم STC Pay ويحوّل القطة ثم يضغط «دفعت».
- **المشرف:** يفتح تمرين جديد بالتاريخ والوقت، يحفظ التشكيلة ويبدّل اللاعبين، يسجل النتيجة والأهداف، يحدد القطة (إيجار كامل ينقسم أو مبلغ على الشخص) وطريقة الدفع (آيبان، STC Pay، رابط دفع) ويأكد مين دفع ويذكّر اللي ما دفعوا بالواتساب، يحذف تمرين، ويغير الرموز.

## التجربة على جهازك
إذا `firebase-config.js` فاضي، التطبيق يشتغل بـ"وضع التجربة" ويحفظ في المتصفح بس:

```
python3 -m http.server 8000
```
وافتح `http://localhost:8000`.

## ملاحظات
- كل تمرين له نتيجة وحدة (مباراة وحدة بين الأزرق والبيج).
- المستوى = (الفوز + نص التعادل) ÷ عدد المباريات. اللاعب الجديد يبدأ من 50%.
- الرموز تنحفظ مشفرة (hash)، وهي حماية بسيطة تكفي لقروب أصحاب، مو حماية بنكية.
